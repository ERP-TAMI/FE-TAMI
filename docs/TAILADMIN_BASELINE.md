# TailAdmin baseline

FE-TAMI was copied from the local TailAdmin React source at
`F:\CONGTYMAY\_tailadmin_react_source`, which tracks the official React
repository:

- https://github.com/TailAdmin/free-react-tailwind-admin-dashboard
- Baseline commit: `21dc917`

The HTML repository listed in the original ticket is a different baseline. The
React source was used here because FE-TAMI is a React application. Demo routes
and demo-only components were removed while the responsive shell, navigation,
theme context, icons, and visual language were retained.
